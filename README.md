# FitTogether

FitTogether is een sportapp die ik heb gemaakt als prototype voor mijn project. Het idee is dat vrienden samen kunnen sporten, activiteiten kunnen plannen en elkaar kunnen motiveren om actief te blijven.

Wat zit er in de app?

In de app kun je je profiel aanpassen, vrienden toevoegen en sportactiviteiten plannen. Je kunt ook geplande activiteiten bekijken, maaltijden plannen en challenges volgen. Daarnaast kun je je voortgang bekijken om te zien hoe je bezig bent met je sportdoelen.

De code

`index.html`

In dit bestand staat de opbouw van de app. Hierin staan de verschillende schermen, knoppen, teksten en invoervelden die je in de app ziet. De HTML bepaalt welke onderdelen er op de pagina staan.

`style.css`

Dit bestand bepaalt hoe de app eruitziet. Hierin staan onder andere de kleuren, achtergronden, knoppen, kaarten, afstanden en de indeling van de verschillende onderdelen. Ik heb gekozen voor groen, lichtgroen en wit om de app rustig en overzichtelijk te houden.

`script.js`

In dit bestand staat de JavaScript-code die ervoor zorgt dat de app interactief is. Hiermee werken bijvoorbeeld het wisselen tussen schermen, het aanpassen van je profiel, het toevoegen van vrienden, het plannen van activiteiten en maaltijden en het bijwerken van de voortgang en challenges.

Afbeeldingen

De afbeeldingen worden gebruikt in de app om de vormgeving aan te vullen.

Gebruikte talen

HTML gebruik ik voor de structuur van de app, CSS voor de vormgeving en JavaScript voor de functionaliteiten.
